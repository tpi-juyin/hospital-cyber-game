# 課前彩排清單

- [ ] 遊戲與主持台文案統一使用「掃描」。主持台點擊 QR Code 可放大，關閉按鈕、點擊背景與 Esc 均可關閉；公開網址改變或連線失效時不保留舊放大圖。

- [ ] v1.11.2 主持台 QR Code 下方「重建公開連線」先顯示遊戲確認視窗，取消不影響活動；確認會中止對局且不計勝負、清空玩家與房間，等待新的 QR Code 後重新掃描加入。
- [ ] 重建時不得重複按下；失敗顯示原因與重試。原活動局長、大招及投降設定保留，原本暫停加入者仍保持暫停。舊網址與憑證不再沿用。
- [ ] 確認使用 v1.11.2 主持包；Windows／Intel Mac 尚未原生執行，需在實際主持電腦先完成啟動與停止彩排。

- [ ] 使用適合主持電腦的主持包，完整解壓縮到本機可寫入資料夾。
- [ ] 接上電源，確認活動期間電腦不進入睡眠。
- [ ] 確認主持頁與手機頁均顯示同一新版版本號；更換主持包後必須重新啟動主持。
- [ ] 啟動並開啟本機主持頁，確認公開入口已就緒。
- [ ] 手機關閉 Wi-Fi，以行動網路掃 QR Code；完成攻擊方與防守方單人各一局。
- [ ] 兩支手機用四位房號／邀請連結加入同一房間，雙方準備後同步開局。
- [ ] 主持頁開啟／關閉「顯示玩家投降按鈕」，確認進行中房間立即同步；取消確認不結算，確認投降後對方勝利，再次對戰可正常進行。
- [ ] 主持頁開啟「大招模式 · 持續 5 秒」，等待中的房間須重新準備；已倒數或進行中的房間維持原模式，再次對戰才更新。
- [ ] 三招上方的集氣條只靠有效連點增加，放著或換招都不增加；集滿後變成大招按鈕，按下後繼續連點；持續 5 秒，自動恢復原招式，普通換招冷卻不阻擋開大。每局用完 2 次後不可再開大。
- [ ] 駭客開大時，前三種防護效果較弱；守方大招可有效減傷，即使護盾耗盡仍能保護，但不回血。電腦攻守兩邊都會使用大招。
- [ ] 主持儀表板連動顯示集氣、施放倒數與大招事件；手機集氣條、大招按鈕與三招在窄螢幕仍完整可見，開啟「動畫：少」後警示仍清楚。
- [ ] 大招期間斷線重連，剩餘時間應保留；暫停不集氣，結束後大招停止，再戰集氣歸零。
- [ ] 試玩 30、60、120 秒，確認雙方切換策略都需冷卻 3 秒；選錯防護時即使快速連點也會掉血，及時切換仍能守住。
- [ ] 確認主選單、角色選擇、好友集結、準備、戰鬥、結算及主持頁皆顯示 v1.11.2；在手機窄螢幕檢查集氣條、三招與連點按鈕不用捲動即可操作。
- [ ] 確認預設暱稱、骰子換名、自訂暱稱與重新整理後保存。
- [ ] 調整手機媒體音量，逐一試聽三種攻擊及三種防禦；確認招式動畫各不相同。
- [ ] 確認音符只控制配樂、喇叭只控制音效；測試全部開、只開音樂、只開音效、全部關，兩個按鈕應以相同綠色／斜線表示狀態。
- [ ] 開場能聽到 3、2、1 及開戰提示；只關閉背景音樂仍有倒數音效，關閉音效則沒有。暫停恢復不連續補播舊倒數。
- [ ] 全新開啟手機頁面，先觸控準備；確認倒數與開戰音訊正常。最後 10 秒配樂加速，下一局恢復原速。
- [ ] 確認駭客勝利是皇冠駭客、戰敗是叉叉眼駭客；醫院方結算使用醫院角色，本局情報預設展開，固定兩則與本局常用攻擊／防禦相關的真實知識，仍可收合。
- [ ] 投降彈窗應在中央；取消不投降，確認才結算，背景不誤按，斷線或對局先結束時彈窗自動關閉。
- [ ] 確認開戰後播放配樂，暫停／結束／切到背景時配樂停止；勝利與失敗各有一次不同的提示音，音效關閉時不播放，不計勝負也不播放。
- [ ] 確認半血第一台主機故障、歸零兩台故障，結算與主持投影一致；再戰恢復兩台。攻防技術文字在窄螢幕上仍清楚。
- [ ] 開啟「動畫：少」，確認仍有靜態招式圖形。
- [ ] 一支手機短暫斷線，確認另一支暫停，恢復後可繼續；逾時顯示不計勝負。
- [ ] 主持人開啟「戰況儀表板」，檢查投影可讀性、倒數及暱稱；確認半血備援接手、歸零服務中斷、曲線與事件連動。
- [ ] 確認主持總覽與儀表板都採深色配色；QR Code 仍是淺底，手機掃描正常，活動設定與房間狀態文字清楚。
- [ ] 對戰暫停／結束時曲線應凍結，主持頁斷線時應顯示最後資料提示；按 Esc 或返回總覽正常回到房間列表。
- [ ] 說明 CPU、記憶體與服務延遲均為遊戲模擬，並非真實醫院監控。
- [ ] 與實際授課用 Zoom、投影、影片一起測試網路。
- [ ] 停止主持後確認舊網址失效，重新啟動產生新 QR Code。

若當天網路不允許公開通道，請先處理連通性再開放玩家加入。僅能開啟一般 HTTPS 網站，不代表 TCP 7844 已可用。

- [ ] 單人選角按出發即倒數，不進準備房；結算再戰回到選角，可更換角色與時間，按出發才倒數。
- [ ] 雙人先開房再選角；雙方可同邊但不能準備，改為不同邊後都準備才開局。換角取消雙方準備，主持台仍能看到兩位玩家。

- [ ] 用邀請連結或房間 QR Code 開啟，直接看到好友集結與暱稱／骰子、金色「點此加入」，不出現房號輸入；按下才加入。一般手動加入仍有房號欄位，雙人房主仍先設定代號再開房。

- [ ] 雙擊啟動檔後，預設瀏覽器自動開啟主持頁；若未開啟，使用命令視窗保留的主持網址。重建公開連線不另開分頁。
