# 實作與驗收順序

1. 戰鬥引擎與協定：以決定性的時間測試勝負、盾值、限速、回合序號及斷線期限。
2. 手機 UI 與單人電腦：入口、等待、倒數、戰鬥與教學結算，所有資源可本機提供。
3. 雙人與多房間：四位房號、角色占用、準備、重連接手；真實 WebSocket 測試房間隔離。
4. 主持與啟動器：入口憑證隔離、即時總覽、投影、公開通道健康檢查及程序清理。
5. 容量測試：30 名模擬玩家分別運行 15 場雙人及 30 場單人，記錄延遲與資源數據。
6. 可攜包：下載固定版本、核對 SHA256、整理授權、輸出三種 ZIP；在可用平台執行啟動／停止檢查。
7. 交付報告：明列已驗證與未驗證的平台；實機瀏覽器依使用者授權另行驗證。
