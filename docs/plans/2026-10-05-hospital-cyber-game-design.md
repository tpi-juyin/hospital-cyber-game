# 醫院資安攻防戰：實作設計

依本對話已確認方案：30 人容量、多房間、單人或双人、玩家自選攻守、卡通街機風、4 位數房號、30～120 秒每 5 秒一格、預設 60 秒。交付 Windows x64、Mac ARM64、Mac x64 可攜包。

前端 TypeScript／Vite，SVG 與 CSS 動畫，手機自行繪圖；伺服器 Node.js／Socket.IO，單程序記憶體狀態、20 Hz 更新、10 Hz 戰況推送。主持和玩家分開 localhost listener；公開通道只連玩家入口，主持憑證由本機啟動器提供。

遊戲血量 100、護盾 30；攻擊傷害 1、補盾 0.9，兩者乘 60/局長；對應／非對應防護每盾吸收 1.25／0.5 傷害。每秒最多 6 次有效連點，攻擊切換冷卻 3 秒、防守 0.5 秒。電腦每秒 4 次，攻方每 4 秒切換、防方延遲 0.9 秒且 80% 選對。伺服器收到操作時先判定截止時間，不採信前端時間或血量。

攻防：密碼猜測／多因素驗證、流量轟炸／流量限制、漏洞入侵／安全更新。教學以多層防護為前提，切換只代表加強重點，遊戲不發出真實攻擊。

房號為 1000～9999，同一活動不重複使用，內部房間 ID 與私人重連 token 分離。等待→倒數→對戰→結束；斷線可暫停並恢復，单次 10 秒、累計 20 秒，逾時無勝負。雙方準備才能開局；再次對戰重設回合 ID，舊輸入無效。

可攜包附固定版本 Node.js、cloudflared、已建置遊戲、啟動器與授權檔。啟動器不依賴主機既有 PATH，使用可用連接埠、相對路徑與 HTTP/2 通道；成功驗證公開健康端點後才发布 QR Code。無資料庫、帳號或活動資料搬移。
