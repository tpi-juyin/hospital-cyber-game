## 1.12.1 主持登入來源修正（2026-10-06）

- 真實瀏覽器以假密碼重現原生登入表單遭「無效操作來源」拒絕；僅將文件來源政策改為 same-origin 後，正常進入密碼驗證。原因為 no-referrer 讓原生 POST 表單送出 Origin: null。
- 雲端主持頁改用 same-origin，涵蓋登入、登入錯誤重試及登出；玩家與本機入口政策不變，仍拒絕外站、null 與缺少 Origin 的主持 POST。
- 回歸測試先確認舊版失敗；修正後 94 項測試與正式建置通過。登入成功、錯誤重試、登出及來源拒絕由 HTTP 整合測試覆蓋；1.12.1 已部署，公開瀏覽器確認原生表單與失敗重試均正常進入密碼驗證，未讀取使用者密碼。
