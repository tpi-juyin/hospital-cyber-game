# 醫院資安攻防戰

手機掃描即可玩的卡通資安遊戲。支援單人 VS 電腦、雙人對戰、四位數房號與 30 人同時在線。預設每局 60 秒，可調整 30～120 秒。遊戲只模擬攻防，不接觸醫院系統。

結算的資安情報預設展開，依本局最常使用的攻擊與防禦各顯示一則真實知識，維持兩點短文。內容與查核來源見 [資安知識說明](docs/SECURITY_KNOWLEDGE.md)。

主持台的加入 QR Code 可點擊放大，使用「關閉放大畫面」、點擊背景或 Esc 關閉。公開網址更換、重建中或主持台連線失效時，放大畫面會自動關閉；入口尚未就緒時無法放大。

## 使用可攜式主持包

1. Windows x64 使用 `hospital-cyber-game-windows-x64.zip`；Apple 晶片 Mac 使用 `macos-arm64`；Intel Mac 使用 `macos-x64`。
2. 完整解壓縮到可寫入的本機資料夾，不要在 ZIP 內直接啟動。
3. Windows 雙擊 `start-game.cmd`；Mac 雙擊 `start-game.command`。首次請依作業系統提示允許執行，受管理電腦需符合院內程式執行政策。
4. 保持啟動視窗開啟；服務準備好後會用系統預設瀏覽器自動開啟主持頁，不必等待公開通道連線完成。若未自動開啟，可手動開啟視窗顯示的「主持頁網址」。此連結包含本機主持憑證，請勿傳給玩家。
5. 等待主持頁顯示「公開入口已就緒」，再讓手機掃 QR Code。用手機關閉 Wi-Fi、開啟行動網路先試玩。
6. 單人選擇代號、角色及時間後，按「出發」直接倒數；結算按「再挑戰一局」回到選角頁，可換角色、調整時間或代號，再按「出發」才開局。雙人先設定代號與時間、建立房間，邀請朋友後在房內自由選角；可用預設暱稱或骰子換名。「輸入房號，加入朋友」可輸入四位房號；掃房間 QR Code 或開啟邀請連結會直接進入「好友集結」取名頁；不需輸入房號，選好代號後按金色「點此加入」即可進房。房間滿員、已結束或失效會顯示原因，可留在原頁重試或返回主選單。
7. 活動結束按主持頁「停止主持」，或在啟動視窗按 Ctrl+C。先正常停止再關閉終端機；Windows 直接關閉視窗時須確認程序已結束。

主持包內含 Node.js 24 LTS、cloudflared 與全部遊戲依賴，不需要 npm、Docker、Homebrew、Cloudflare 帳號或網域，也不需在現場下載套件。可移動整個資料夾，支援中文與空白路徑。

Windows 以 Windows 11 x64 為驗收目標；Mac 的 Node.js 執行環境最低 macOS 13.5。Windows ARM、32 位元 Windows 與 Linux 不在本版交付範圍。**打包成功不代表原生系統已驗證；目前實測範圍請看 `docs/TEST_RESULTS.md`。**

## 版本與更新

主持頁、投影畫面與玩家頁左上方顯示版本號，目前原始碼為 v1.13.0。版本由同一份專案版本資料產生。

`release/` 的 Windows x64、macOS ARM64 與 macOS x64 三種主持包已更新為 v1.11.2，包含自動開啟主持頁、重建公開連線、掃描文案及 QR Code 放大功能。Apple 晶片 Mac 已通過本機啟動與遊戲連線檢查；Windows／Intel Mac 尚未原生執行，請先在活動電腦彩排。

更新主持包前請先停止主持，再解壓新版並重新啟動，通知玩家掃描新的 QR Code。若直接在執行中的原始碼資料夾建置新版，主持頁會提示重新啟動；僅重新整理網頁無法更新執行中的伺服器。

## 重建公開連線

主持台 QR Code 下方提供「重建公開連線」。按下後以遊戲風格確認視窗提醒：目前對局中止且不計勝負、所有房間與玩家連線清除，玩家需要重新掃描。取消不會執行。

確認後暫停新玩家加入並撤下 QR Code，只重啟 cloudflared 通道；主持頁網址、遊戲服務與活動設定保持可用。新網址通過健康檢查後顯示 QR Code，恢復重建前的加入設定；若原本暫停加入，仍維持暫停。收到通知的舊玩家頁會顯示重新掃描提示；已斷線或未收到通知的玩家請依主持人指示掃新碼。舊玩家憑證失效，房號不會於同次活動重複發放。

建立約兩分鐘仍未就緒、程序退出或執行失敗時，顯示原因與「重試公開連線」。重建期間不可再次重建，可使用「停止主持」結束活動。重建不能保證解除 Cloudflare 請求限制。

`--local-only` 本機測試模式不提供此功能。更新至此版仍需停止並重開啟動檔一次，載入新版啟動器；之後可直接由主持台重建通道。

## 遊戲方式

攻擊方連點「發動攻擊」，先破盾再扣血；防守方連點「強化防護」補盾。醫院血量歸零，攻擊方獲勝；倒數結束仍有血量，防守方獲勝。雙方各有三種可切換策略：密碼猜測／多因素驗證、流量轟炸／流量限制、漏洞入侵／安全更新。選對防護可提高護盾效率。

主持頁「活動設定 → 顯示玩家投降按鈕」預設為隱藏。開啟後，所有進行中對戰會在目標說明旁顯示「投降」，適用單人與雙人；玩家按下後會在畫面中央出現遊戲風格確認視窗，選「繼續戰鬥」可取消，選「確認投降」才判對方獲勝，保留當下血量與統計，仍可再次對戰。關閉設定會即時隱藏按鈕並禁止投降請求；等待、倒數、重連暫停與結算時不提供投降。確認視窗開啟時對戰計時照常進行；斷線、對局結束或主持關閉投降功能時，視窗自動取消。主持的關閉房間與停止活動也使用相同遊戲視窗。

每人每秒最多 6 次有效連點，長按不會連發。防護選擇代表當下加強的重點，不代表其他安全措施被關閉。雙人可暫時選擇相同陣營，但必須一攻一守且雙方準備才開局。同邊時顯示換邊提示，不能準備；換角或房主變更時間會取消雙方準備。房內可複製邀請連結，也可展開 QR Code。房號僅供尋找房間，重連由私人憑證驗證。

攻守雙方切換策略的冷卻皆為 **3 秒**。1.6.0 調整為每次攻擊 1.15 傷害、每次防守補充 0.7 護盾；每點護盾在防護對應時吸收 1.25 傷害，未對應時吸收 0.25。傷害及補盾量仍乘以 `60 ÷ 局長秒數`，血量 100、護盾上限 30 不變。選錯防護時，單靠較快的連點不能持續抵擋進攻；電腦也遵守相同數值與冷卻。確定性模擬結果見 `docs/balance-results.json`，不代表真人對戰勝率。

暫時斷線會暫停該房間，單次等候 10 秒，每局累計 20 秒；超時不計勝負。同一個瀏覽器分頁刷新可恢復身分；同來源開另一分頁時，較新的分頁接手，避免同一人多開連點。斷線期間的連點不會補送。

等待或結束後閒置 10 分鐘的房間會自動清除；離線玩家 60 秒後釋放。30 人是容量目標，1～2 人也可以玩。

## 大招模式（1.9.0 更新）

主持頁「活動設定 → 大招模式 · 持續 5 秒」開啟後，玩家會在三顆普通招式上方看到集氣條；預設關閉，可先玩一般模式。模式套用到等待中的房間與之後建立／再次對戰的房間；等待中的玩家需重新準備，已開始倒數或開打的對局維持原規則。

- **集滿再按**：只靠大型攻擊／防守按鈕的有效連點集氣，不會自動增加，切換招式也不集氣；集滿後原位置變成大招按鈕，由玩家手動施放，再繼續按原本的大型連點按鈕。每人每局最多 2 次，每次有效點擊增加 `1.25 × 60 ÷ 局長秒數`；30／60／120 秒局分別需要 40／80／160 次集滿。防守方護盾已滿時，有效點擊仍會集氣。持續每秒 4 點時，60 秒局約在第 20、45 秒可施放；實際時間取決於點擊與保留大招多久。
- **駭客「暗網超頻」**：持續 5 秒，攻擊傷害為普通攻擊的 1.5 倍；前三種防護都只能以未對應效率吸收，只有防守大招能有效反制。
- **防守「緊急應變」**：持續 5 秒，先減少 75% 傷害，剩餘部分再由護盾以對應效率吸收；連點補盾量為普通防守的 1.5 倍。可抵擋大招與一般攻擊，即使護盾歸零也能減傷，但不恢復血量。
- **操作與結束**：大招獨立於一般招式的 3 秒冷卻。施放期間固定使用第四招，5 秒後自動恢復原招式；不提高每秒 6 次的有效連點上限。集氣在大招期間及重連暫停時停止，暫停也保留大招剩餘時間；比賽結束則立即停止大招。
- **提示與電腦**：集氣條顯示進度；集滿變成按鈕，施放時顯示剩餘秒數，結束後回到集氣條；駭客開大會顯示警示，守方已就緒的第四招會閃亮。新增紫金閃電及巨盾的圖形特效與音色，減少動畫設定仍有效。電腦同樣需要集氣，攻方集滿施放，守方保留大招，在攻方施放約 0.65 秒後反制；若尚未集滿，需等集滿才能施放。
- **主持投影**：儀表板同步雙方集氣、施放時間、已用次數與大招事件；一般模式隱藏這些資訊。

大招是教學遊戲的簡化機制。真實緊急應變只能爭取處理時間，仍需要多因素驗證、流量管理、安全更新等持續防護。

## 主持戰況儀表板

主選單、角色選擇、好友入房、準備、戰鬥、結算、主持總覽與戰況儀表板統一採深藍街機風格，搭配紫色進攻、青綠防守與金色主要按鈕。結算顯示自己的陣營角色：駭客勝利戴皇冠、戰敗呈現叉叉眼；資安解說收在可展開的「本局情報」。QR Code 保留淺底深色圖案，方便手機掃描。主持頁點選房間的「戰況儀表板」，開啟醫院伺服器監控台；右上可返回總覽，也可按 Esc。畫面保留房號、版本、倒數、雙方暱稱、策略與結算結果，適合筆電及投影展示。

- **雙機運作**：血量大於 50 時主機服務、備援同步待命；血量降至 50 以下時主機故障，由備援機承接；血量歸零時兩台離線、四項醫療服務中斷。投降按實際血量呈現，不會假造主機故障。
- **戰況指標**：健康度與護盾直接使用伺服器判定值；攻擊與防護攔截曲線來自每次收到的累積次數，顯示近 2 秒平均及最近 30 秒趨勢。攔截包含部分吸收傷害的攻擊與緊急應變減傷。
- **負載及服務模擬**：CPU、記憶體、掛號／病歷／檢驗／醫囑的回應時間依遊戲中的攻擊強度、策略與血量推算。全畫面及相應卡片標示模擬，不讀取真實筆電、醫院主機或病人資料。
- **防護與事件**：呈現三項持續啟用的基礎防護及目前加強項目；記錄開戰、策略切換、護盾耗盡、主備切換、重連及結算。
- **更新與暫停**：主持頁約每 0.5 秒更新，曲線在對戰暫停／結算時凍結。主持頁連線失敗時顯示最後資料提示；恢復後不把斷線期間的累積攻擊當成瞬間流量尖峰。
- **紀錄範圍**：曲線與事件只保存在目前主持頁記憶體，重新整理會重新累積；切換房間互不混用，再次對戰清空該局紀錄，房間關閉時自動返回總覽。

## 音樂、音效與動畫（1.6.0）

- 戰鬥採原創 168 BPM 街機戰鬥配樂，最後 10 秒加快至 210 BPM（快 25%），保留當前旋律進度，再戰恢復原速；含八小節主旋律、疾走低音、強力和弦、重鼓、軍鼓、踩鈸與過門，直接由 Web Audio 產生，不需下載音樂檔。玩家點擊準備等操作啟用音訊，正式開戰後播放；等待、倒數、暫停、斷線、結算或切到背景時停止。
- 頂端喇叭只控制攻防、倒數與勝敗音效，音符只控制戰鬥配樂，兩者完全獨立。兩個按鈕都以綠色表示開啟、斜線表示關閉；可只留音樂、只留音效、全部開啟或全部關閉。設定保留在該瀏覽器。
- 開場 3、2、1 各播放一次短音，正式開戰有較高的雙音提示；依伺服器倒數同步，漏掉的節拍不補播，重複狀態與暫停恢復不重播同一秒。關閉音效或切到背景時不播放。
- 勝利播放上揚和弦；失敗改為較高音域、較長且帶泛音的下降旋律，以改善手機喇叭辨識度，實際音量與聽感仍需手機試聽。同一局的結算更新或切換偏好不會重播，不計勝負時不播放勝敗提示。
- 醫院圖案有兩台無文字標示的主機。血量降到 50 時第一台灰掉、冒煙並露出叉叉眼，歸零時兩台都故障；結算與主持投影保留目前狀態，再次對戰時恢復。這是血量視覺化，不改變原有攻防數值。攻防技術名稱加大為 14px 粗體。
- 駭客採亮紫色斗篷、藍灰色電腦與亮綠圖示，保留深色臉部、紅眼及邪惡表情，提升小尺寸辨識度。
- 三種攻擊以鑰匙火箭、火焰彈、紫色小蟲呈現；三種防禦以彈跳護盾、反彈柵欄、修補彩星呈現，各有專屬音效。特效使用純圖形、不顯示招式字幕，連點時保留飛行中的前幾發特效。自己點擊立即回饋，電腦或對手的動作依伺服器狀態呈現。
- 「動畫：少」保留靜態招式圖形，停用動態效果。「防護未對應」使用深紅字、淡橘底與警示符號，方便及時切換策略。暱稱提供 144 種組合，擲骰子保證與當前名稱不同，仍可自行編輯。

手機是否能出聲仍受媒體音量與瀏覽器播放政策影響。觸控在放開手指時啟用音訊，滑鼠與鍵盤仍可啟用；手勢時機依照 [MDN 使用者啟用說明](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/User_activation)。音訊啟用方式另參照 [Chrome Web Audio 說明](https://developer.chrome.com/blog/web-audio-autoplay)；戰鬥配樂及音效為本專案合成內容，未使用第三方歌曲。

## 網路與主持注意事項

- 保持電腦連網、接電，活動期間不要睡眠或關閉啟動視窗。
- 需要 DNS、HTTPS 與向 Cloudflare Tunnel 的 TCP 7844 對外連線。通道使用 HTTP/2，不要求 UDP 7844。
- 不需固定 IP、對外開放本機連接埠或設定路由器轉發。兩個服務都只監聽 `127.0.0.1`；只有玩家入口透過通道公開。
- 受管制網路若無法連線，請資訊人員依官方需求允許，或改用可連通的手機熱點。請勿停用系統防護。
- 臨時網址每次重新啟動不同，停止後失效；換電腦是全新活動，不搬移進行中的房間。
- Quick Tunnel 沒有可用性保證。網址通過健康檢查才顯示 QR Code；持續檢查失敗會撤下，避免分享失效入口。
- 授課若同時使用 Zoom、投影與影片，請以當天網路與全部工具一起預演。

參考：[Cloudflare Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)、[通道防火牆需求](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/tunnel-with-firewall/)。

## 啟動失敗時

| 畫面或訊息 | 處理方式 |
|---|---|
| 已有遊戲正在主持 | 使用顯示的原主持頁，或先停止原活動；不要重複啟動。 |
| 缺少檔案／無法執行工具 | 確認選對平台、完整解壓縮、使用者可寫入資料夾，並依系統政策允許執行。 |
| 公開通道尚未連通 | 等候 DNS 就緒，確認 TCP 7844／HTTPS 可通；查看 `logs/`。 |
| 公開通道停止 | v1.11.2 使用主持台「重試公開連線」，確認後等待新 QR Code，再讓玩家掃描；舊版主持包需停止再啟動。 |
| 主持憑證失效 | 使用啟動視窗顯示的完整主持連結。不要使用其他活動的書籤。 |
| 手機顯示 30 人已滿 | 等其他玩家離開，或等斷線席位釋放；重試加入。 |

`logs/` 保留啟動與通道診斷，`.runtime/` 為本次本機活動資訊。回報問題只需分享診斷紀錄，不要分享 `.runtime/instance.json`。停止活動會清除主持入口資訊，但保留 logs 供排錯。

## 從原始碼開發

建議使用 Node.js 24 LTS：

```sh
npm ci
npm run build
npm test
npm run test:load
npm run start:local
```

`start:local` 只提供同一電腦的測試入口，手機不能藉此跨網路加入。公開主持使用 `npm start`，需有 cloudflared 或 `runtime/` 內的執行檔。啟動器不會自動操作瀏覽器。

```sh
npm run package
```

打包需要網路及 `tar`、`unzip`、Python 3，目前打包工具以 macOS／Linux 執行。固定下載 Node.js 24.21.0、cloudflared 2026.9.1，校驗 Node 官方 SHA256 與 GitHub release 的資產 digest。啟動檔統一使用英文檔名，並輸出版本資料與 SHA256SUMS；執行主持包時不需這些打包工具。

程式採記憶體狀態，服務重啟清空，不收集病人資料。第三方套件與執行環境授權見 `THIRD_PARTY_LICENSES.md` 與主持包的 `licenses/`。

啟動器可加上 `--no-open` 停用自動開啟瀏覽器，例如 `npm start -- --no-open`；自動化檢查均使用此參數，不會操作瀏覽器。重建公開連線不會再次開啟主持頁。
